## 📋 Tentang Project

**Crypto Tracker** adalah aplikasi web untuk memantau harga cryptocurrency secara real-time dan mensimulasikan portofolio investasi. Dibangun dengan **Next.js 16** dan **TypeScript**, aplikasi ini membantu pengguna dalam :

- 📊 Memantau top 20 cryptocurrency berdasarkan market cap
- 🔍 Mencari aset kripto berdasarkan nama atau simbol
- 🌓 Menyesuaikan tampilan dengan mode terang/gelap
- 💼 Mensimulasikan portofolio investasi (keuntungan/kerugian)
- 📈 Melihat grafik harga 7 hari terakhir

## ✨ Fitur Utama

- 🏠 **Dashboard** - Tampilan 20 crypto teratas dengan harga real-time
- 🔎 **Live Search** - Filter crypto berdasarkan nama atau simbol
- 🌙 **Dark Mode** - Toggle tema dengan deteksi preferensi sistem
- 📊 **Modal Detail Coin** - Informasi lengkap (market cap, volume, supply, ATH)
- 📈 **Mini Chart** - Grafik harga 7 hari dengan tooltip interaktif
- 💼 **Portfolio Simulator** - Simulasi kepemilikan aset + perhitungan P&L
- 🗑️ **Manajemen Aset** - Tambah, hapus, dan update portofolio
- 🔔 **Toast Notification** - Notifikasi modern (bukan alert bawaan)

## 🛠️ Tech Stack

| Kategori | Teknologi |
|----------|-----------|
| **Framework** | Next.js 16 (App Router) |
| **Bahasa** | TypeScript 5.x |
| **Styling** | Tailwind CSS 3.x, shadcn/ui |
| **Chart** | Recharts |
| **Animasi** | Framer Motion |
| **API** | CoinGecko API |
| **Deploy** | Vercel |

## 🚀 Cara Menjalankan

```bash
# Clone repository
git clone https://github.com/ViannKia/CrypTracker.git

# Masuk ke folder project
cd crypto-tracker

# Install dependensi
npm install

# Jalankan development server
npm run dev
```
